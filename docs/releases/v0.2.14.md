# MARVEL v0.2.14

发布日期：2026-10-22

首个 MARVEL 自有版本，包含消息层、辩论复核、界面与发布工程。

## 消息

- 公告按窗口取数并翻页，历史窗口不再为空。
- 新增公告正文抓取；修复财联社接口；全球快讯改为三源合并。
- 新闻条目标注「多源印证 / 单一来源，未经交叉验证」。

## 辩论与复核

- 质量门控核对来源标注是否被如实传递。
- Research Manager 收到来源印证摘要，并显式声明未核实依赖。
- 最终决策中的未证实说法进入独立附录；记忆日志不再回注这些内容。
- 新增真实模型录制与 A/B 对照工具。

## 界面与导出

- Web UI 改为「夜读研报台」：墨纸配色、宋体研报正文、朱砂评级印章。
- PDF 导出同步排版；修正 A 股红涨绿跌。

## 修复

- DeepSeek Flash 结构化输出不再触发 400。
- 桌面启动器检测陈旧服务。
- 历史窗口取数、全球快讯与新浪第二页等修复。

## 安装

GitHub Release 提供 wheel 与 sdist。PyPI 配置 trusted publishing 后：

```bash
pip install marvel-astock==0.2.14
```

导入包名仍是 `marvel`。
